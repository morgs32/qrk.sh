# Existing React insertion controls

Researched 2026-10-20 from first-party documentation and source. **Yes: the hover-to-insert pattern already exists.** The closest line-and-plus example is Gutenberg between blocks; the strongest table examples are editor-owned footer controls. They differ from Studio's centered circle between every pair of Items.

## Concrete matches and differences

| Example | Confirmed behavior | Reuse boundary |
| --- | --- | --- |
| **WordPress / Gutenberg** | Hover the gap between two blocks to reveal a horizontal blue line and Plus inserter. Clicking opens the block chooser. This is the closest behavioral match for the between-content separator. | Part of the block editor's insertion flow, rather than a standalone callback button. [Official behavior documentation](https://wordpress.org/documentation/article/adding-a-new-block/#using-the-block-inserter-icon-in-between-blocks), [maintainer discussion of editor-store coupling](https://github.com/WordPress/gutenberg/issues/65290). |
| **BlockNote** | Last-row/below-table hover reveals a full-table-width row extension button below the table. The centered Plus appends one row; dragging extends or crops the table. Between-row insertion uses gutter menu actions instead. | React controller and button depend on BlockNote editor hooks and table commands. It provides a shadcn renderer, but no inspected generic line-and-circle separator. [Controller](https://github.com/TypeCellOS/BlockNote/blob/main/packages/react/src/components/TableHandles/TableHandlesController.tsx), [hover ownership](https://github.com/TypeCellOS/BlockNote/blob/main/packages/core/src/extensions/TableHandles/TableHandles.ts), [extension behavior](https://github.com/TypeCellOS/BlockNote/blob/main/packages/react/src/components/TableHandles/ExtendButton/ExtendButton.tsx), [shadcn button](https://github.com/TypeCellOS/BlockNote/blob/main/packages/shadcn/src/tableHandle/ExtendButton.tsx). |
| **Yoopta shadcn table** | An 18px-high, full-width Plus button appears below the table on last-row hover, with a 150ms hide delay. Side handles supply insert-above/below menus. This is a footer, not an inline separator. | Its button markup is simple, but behavior uses `useYooptaEditor` and `TableCommands`. [Add-row button](https://github.com/yoopta-editor/Yoopta-Editor/blob/master/packages/themes/shadcn/src/table/components/add-row-button.tsx), [hover controller](https://github.com/yoopta-editor/Yoopta-Editor/blob/master/packages/themes/shadcn/src/table/components/table-controls.tsx), [row menus](https://github.com/yoopta-editor/Yoopta-Editor/blob/master/packages/themes/shadcn/src/table/components/row-controls.tsx). |
| **beUI editable Table** | Row hover reveals a handle at the left border. Its menu offers Insert before/after and calls `onInsertRow(index, position)`. | Published React source includes `components/motion/table/row-handle.tsx`; it uses a DOM row reference, a portal, and `TableMenu`. This is a callback-based reference with less editor coupling, but the UI is a side menu rather than a Plus rule. [Official demo and source](https://beui.dev/components/motion/table#editable-table). |
| **Dice UI Data Grid** | Its full-width bottom footer shows Plus and **Add row**, calling `onRowAdd`. It is not a between-row hover separator. | The footer lives inside the grid viewport and uses table/grid state. Source is editable through its registry workflow. [Documentation](https://diceui.com/docs/components/radix/data-grid), [footer source](https://github.com/sadmann7/diceui/blob/main/docs/registry/bases/radix/components/data-grid/data-grid.tsx). |

Other React grid examples are weaker matches: **React Datasheet Grid** exposes a replaceable bottom `addRowsComponent` with an `addRows` callback, while **Glide Data Grid** exposes a clickable empty trailing row via `onRowAppended`. Neither cited feature supplies the between-row Plus separator. [React Datasheet Grid props](https://react-datasheet-grid.netlify.app/docs/api-reference/props/#addrowscomponent), [custom add button](https://react-datasheet-grid.netlify.app/docs/i18n/#add-button), [Glide API](https://github.com/glideapps/glide-data-grid/blob/main/packages/core/API.md#onrowappended).

## Recommendation

**Keep Studio's small local `ItemInsertionSeparator`; use Gutenberg as the interaction precedent and BlockNote/Yoopta as table-footer references.** This is a design/reuse judgment: importing a table or rich-text editor would add ownership that Studio's existing callback does not need. None of the inspected candidates supplies the exact hollow centered-circle control as a generic insertion primitive.

Official shadcn already supplies the underlying Table, Button, and Separator primitives; its Data Table guide demonstrates composing application-specific table behavior. Its inspected Table/Data Table docs did not provide this insertion widget. [Table](https://ui.shadcn.com/docs/components/radix/table), [Data Table guide](https://ui.shadcn.com/docs/components/radix/data-table).
