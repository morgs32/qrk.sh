# QRK glossary

| Term                    | Meaning                                                                                                                                                                                                                                                                                |
| ----------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Article                 | A brick with a title, subtitle, and Markdown body. Its content is shared across breakpoints; its Placements are arranged independently in each breakpoint Wall.                                                                                                                        |
| Article body            | The formatted text below an Article's title and subtitle. An empty or null body contains no body text.                                                                                                                                                                                 |
| Article draft           | Changes to an Article’s title, subtitle, or body that the mounted Studio editor still holds before local staging succeeds.                                                                                                                                                             |
| Committed Article       | Article content applied by the canonical system. Public readers see the version captured in the current published Page snapshot.                                                                                                                                                       |
| Favicon                 | An icon representing a website, used to identify the site in a browser or other interface. |
| Mask icon               | A site-provided shape intended to be colored by the interface that displays it. |
| Index page              | The site's required page at `/`. Publishing a site always includes this page.                                                                                                                                                                                                          |
| Published site          | A site whose public availability is enabled. Turning availability off retains its page publication choices and history.                                                                                                                                                                |
| Published page          | A page marked for public access when its site is available. Visitors use its current published snapshot while saved editing changes remain private.                                                                                                                                    |
| Page snapshot           | An immutable version of saved page metadata, brick content, and layouts captured by a publication. Each publication retains a new snapshot in the page's history.                                                                                                                      |
| Publish updates         | Replace a published page's current snapshot with a new snapshot of its saved content, retaining the previous snapshot.                                                                                                                                                                 |
| Page                    | A site's editable document. It owns shared Brick content and four breakpoint Walls, plus metadata and publication state.                                                                                                                                                               |
| Breakpoint              | One of the four canonical page widths: sm (360), md (720), lg (1080), or xl (1440). Each has its own Wall arrangement.                                                                                                                                                                 |
| Wall                    | The saved arrangement of one Page at one breakpoint. It owns an ordered layout tree of Sections, named Stacks, Rows, and Placement references and has no user-facing label.                                                                                                            |
| Section                 | An ordered horizontal band containing Stacks. A Section can remain empty; deleting a Brick prunes it only when that deletion removes its last Stack.                                                                                                                                   |
| Stack                   | An independently movable, named container of vertical Rows within one Section. A Section divides its width according to its Stacks' saved proportions, constrained by each Stack's widest Row and Brick minimums. An empty Stack reserves at least 160px plus its gap allowance. It retains its Rows and identity when moved; unrelated moves preserve empty Stacks. Deleting a Brick prunes it only when that deletion removes its last Row. |
| Row                     | An ordered container within a Stack that spans the Stack. Its Placements share one surface height and may leave horizontal space. Its saved minimum or automatic module preferences establish the height floor; taller content or an insertion shadow may grow it. Deleting its last Brick removes the Row; unrelated empty Rows remain untouched. |
| Compatible Row          | A Row whose variant-sharing rules allow a new Brick or moved Placement. An empty Row accepts any variant; otherwise only fixed-height variants may share. A compatible Row is an available destination only when the resulting Section also fits its Wall without violating Brick minimum widths. |
| Variable-height variant | A module variant whose shared `defaultHeight` is null. It occupies its Row alone; additions and moves cannot place another Brick beside it.                                                                                                                                            |
| Placement               | One appearance of a shared Brick in a breakpoint Wall. Its separate record owns the variant, relative width weight, rendering spec, revision, and generation state. It may move within or between Rows of its Wall while preserving its identity and shared content.                                          |
| Width weight | A Placement’s positive preferred width in pixels. Module preferred width supplies its initial value. It becomes a proportion when fitting a constrained Row. A completed divider resize derives the Row’s weights from its measured surface widths. |
| Row alignment | Left, Center, or Right placement of the Brick group within its Row. |
| Row minimum height | A Row’s saved minimum surface height in pixels. Null uses automatic module height preferences. Module minimums and taller content can increase the shared height. A completed height resize saves the visible result; double-click or double-tap restores automatic height. |
| Brick                   | Page-owned content configured through a module. Its content is shared by one Placement in each of the Page's four Walls. A null draft or historical null content means unconfigured.                                                                                                     |
| Brick category          | A curated grouping used to filter Brick choices in the editor's drawer. A Brick module can belong to multiple categories. |
| Brick drawer row        | A curated set of related Brick previews displayed together in the editor's drawer. Each preview offers a starting layout and example content. |
| Image crop              | The focal point and zoom of an Image Brick’s original photo. Every Placement of that Brick frames the same photo in its own dimensions. |
| Spotify Brick           | A Brick that presents a creator-selected Spotify track, album, playlist, artist, show, or episode in Spotify's player. |
| YouTube Brick           | A Brick that presents a creator-selected YouTube video or playlist in YouTube's player. |
| Selected Brick          | A Brick with a persistent Wall outline. Clicking an Article selects it while leaving it editable in its Placement. Selecting a sidebar-backed Brick opens Edit Brick. |
| Active                  | DOM focus, including keyboard focus, within the wall editor.                                                                                                                                                                                                                           |
| Breakpoint Previews     | A Storybook view that compares a module's JSX sketch and JSON Render at the four Breakpoints using one example state and one active spec. |
| QRK design system | The shared UI controls and visual defaults that Bricks supplies to QRK App, Web, and Storybook. |
| Item (historical)       | The earlier tree prototype's content row. Current editor terminology uses Placement inside a Row.                                                                                                                                                                                      |
