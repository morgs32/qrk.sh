# shadcn/ui docs navbar height

Checked 2026-11-11. The published Components page uses a **3.5rem (56px)** navbar below `lg` and **4rem (64px)** at `lg` and wider, at a 16px root font size. The page HTML sets `--header-height` to 14 spacing units and overrides it to 16 at `lg`. Its sticky site header applies that variable to the navigation row. The published HTML matches the upstream source. [Components page](https://ui.shadcn.com/docs/components) · [Root layout](https://github.com/shadcn-ui/ui/blob/dd41d19e2f80ff6891951f7ced74c2c9a650b065/apps/v4/app/layout.tsx#L75-L82) · [SiteHeader](https://github.com/shadcn-ui/ui/blob/dd41d19e2f80ff6891951f7ced74c2c9a650b065/apps/v4/components/site-header.tsx#L21-L24) · [Tailwind spacing and breakpoints](https://github.com/tailwindlabs/tailwindcss/blob/main/packages/tailwindcss/theme.css#L298-L304).

QRK's shared dashboard and editor header uses `h-14 lg:h-16`. Its Tailwind border-box height includes the bottom border. Browser checks on both routes measured 56px at a 900px viewport and 64px at a 1205px viewport.
