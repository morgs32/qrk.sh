# `.plans`

All plans and specs for this repo live here.

| Path | Contents |
|------|----------|
| `.plans/plans/` | Implementation plans (`XXX-plan-<topic>.md`) |
| `.plans/specs/` | Design specs from brainstorming (`XXX-spec-<topic>.md`) |
| `.plans/archived/` | Fully implemented and verified plans, plus any associated specs used for their implementation (same filenames as when active) |

Allocate the next three-digit `XXX` for every new spec/plan pair or standalone plan by finding the highest three-digit filename prefix anywhere under `.plans/` and incrementing it. A plan derived from a spec reuses the spec's exact `XXX` and topic.

Do not write plans or specs under `plans/`, `docs/superpowers/plans/`, or `docs/superpowers/specs/`.
